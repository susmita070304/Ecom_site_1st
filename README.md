# Comfy Home - E-commerce Website

## Overview

Comfy Home is a modern furniture and home decor e-commerce web application built using React and Tailwind CSS. The application allows users to browse products, view detailed product information, manage their shopping cart, create accounts, and complete purchases through a simple checkout process.

## Features

* Product browsing and detailed product pages
* Shopping cart with quantity management
* User authentication (Login & Signup)
* Responsive navigation menu
* Order confirmation page
* Order history page
* FAQ section
* Contact and Feedback pages
* Redux state management for cart functionality
* Modern UI built with Tailwind CSS

## Technologies Used

* React.js
* React Router DOM
* Redux Toolkit
* Tailwind CSS
* JavaScript (ES6+)
* Vite

## Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate to the project folder

```bash
cd ecom-site
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```
